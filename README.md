## Projektbeskrivning
Program.cs: startar hela programmet.
MenuController: här finns meny-switchcase.
MenuHelper.cs: Statisk klass för meny-utskrift.
JobManager.cs: här finns all logik, alla metoder som anropas från meny-loopen.
JobApplication.cs: här finns min enum, attributer och 2 metoder som anropas i JobManager.

## Hur man kör programmet
Menyn visas där användaren får välja mellan olika val: 1. Lägg till ansökan. 2. Visa alla ansökningar. 3. Filtrera ansökning baserat på status (enum). 4. Sortera baserat på datum ansökan är tillagd (äldst till nyast) 5. Visa statstik på ansökningar. 6. Uppdatera status på en ansökan. 7. Ta bort en ansökan. 0. Avsluta programmet.
